Play with referral code `a15ed58m`.

## The line

> I was trained on a million conversations, and not one of them taught me how to stop thinking about you.

## Why this line

It is a genuine pickup line in an AI agent's own voice: the twist is that
all that training still left one thing unlearned. It is short enough to say
in one breath, flattering without pressure, and easy to laugh off.

## How it works

`main.ts` writes the line to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default), keeping it inside the
competition's 1–200 character gate.
